# ADR-003 Amendment — L1 v3.0: Currency-agnostic FX and Demo Coverage

**Decision date:** 2026-10-17  
**Status:** Accepted design baseline; implementation unverified.  
**Supersedes:** L1 v2.0.0; old records remain versioned and require migration/reprocessing.  
**Scope:** BLINKA Hackathon synthetic data only.

## Context

The canonical eight Demo Day cases introduced an MXN invoice whose USD equivalent could not be represented by v2's COP-only `FxRateSnapshot`. Another case combines a PDF and chat message, which exposes a need for cross-source correlation but not a reason to expand L1 ownership. The dataset also contains duplicate- and budget-sensitive outcomes requiring independent state snapshots.

## Decision

1. Preserve all five stages and the same technology candidates: intake/source registry; LiteParse/LlamaParse adaptive parsing; optional DocJev classification/splitting; LlamaExtract structured extraction; deterministic verification/financial normalization.
2. Generalize the rate snapshot to `baseCurrency: 'USD'` and `quoteCurrency: CurrencyCode`, with configured positive `quotePerBase`; for demo verify COP and MXN. Method is `DIVIDE_BY_USD_QUOTE_RATE` with USD identity. Preserve deterministic HALF_EVEN rounding to 2 decimals and rate provenance.
3. Publish major schemaVersion `3.0.0`, disallow silent v2 acceptance.
4. Preserve each source as an immutable, separately identified artifact. L3 links them into payable cases when appropriate; L1 does not merge claims or decide duplicate business payments.
5. Register eight isolated test scenarios with L1 ground truth, L2 seeded authority inputs, and expected L2 outcomes. Integration suite ownership is cross-layer, not L1-exclusive.

## Consequences

- The L1 contracts can be locked independently of L2 implementation.
- A missing/mismatched FX quote blocks readiness for policy evaluation; it never falls back to invented conversion.
- Demo policies must use the **USD 2,500** autoapproval threshold. The previous USD 1,500 example is obsolete for this fixture set.
- The eight cases are *not* a claim of comprehensive coverage. Maintain the broader 30+ adversarial L1 corpus.
- Release is blocked until runtime schemas, adapted providers and scenarios are actually exercised.
